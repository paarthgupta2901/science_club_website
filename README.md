# ABC School Science Club

A beginner-friendly HTML website created as a practice project to learn the fundamentals of HTML.

## About

The ABC School Science Club website is a simple static webpage designed for a fictional school science club.

It contains information about the club, activities, weekly schedule, team members, important notices, useful links, and contact information.

## Features

* Club introduction
* Navigation links
* Science club activities
* Weekly activity schedule
* Team member list
* Science Fair notice
* Useful external links
* Contact information
* Basic HTML formatting
* Images and tables

## Technologies Used

* HTML5
* Basic Inline CSS

## Purpose

This project was created while learning HTML and practicing different HTML elements such as headings, paragraphs, links, lists, tables, images, formatting, subscript, superscript, and sections.
